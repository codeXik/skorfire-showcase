# SkorFire Live Football — vitrin

Canlı skor, günün maçları, puan durumu ve gol bildirimi; tarayıcı araç çubuğunda. Ücretsiz, hesapsız, reklamsız, izleyicisiz. Chrome, Edge, Firefox; 19 dil.

> Bu repo bir vitrindir; kaynak kod özeldir. ESPN ile bağlantılı değildir.
